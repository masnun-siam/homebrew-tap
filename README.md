# homebrew-tap

Homebrew formulae and casks for [@masnun-siam](https://github.com/masnun-siam)'s tools.

```bash
brew install masnun-siam/tap/cc-profiles
brew install masnun-siam/tap/meqat
```

## Formulae

| Formula | Description |
|---|---|
| [`cc-profiles`](https://github.com/masnun-siam/cc-profiles) | Run multiple Claude Code accounts in parallel from one shared setup |

## Casks

| Cask | Description |
|---|---|
| [`meqat`](https://github.com/masnun-siam/meqat) | Menu bar prayer times, prohibited windows and per-event alerts (macOS 14+) |
